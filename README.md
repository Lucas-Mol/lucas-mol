# Hi, I'm Lucas Mol 👋

**Senior Software Engineer · Backend & Distributed Systems**
Java · Spring Boot · Go · Microservices · Kafka · AWS

I build and modernize backend systems for mission-critical, high-traffic platforms, with 7+ years of experience across financial services, public sector and research projects.

- 🏗️ **Software architecture & distributed systems:** DDD, design patterns and resilience patterns (e.g. deadline propagation) applied to 24/7 multi-tenant microservices and asynchronous, event-driven architectures
- ⚡ **Performance:** cut p99 latency from ~15s to ~3s by moving third-party integrations to async processing; 88.5% faster average response times on a legacy platform
- 🔄 **Modernization:** led the migration of a Java 8 monolith into Spring Boot microservices and Go schedulers
- 🔐 **Security:** OIDC / OAuth 2.0 single sign-on across multiple services; DevSecOps practices across the SDLC
- 🚀 **Delivery & observability:** Kubernetes deploys with Helm, ArgoCD and canary releases; Datadog, Splunk and Grafana
- 🎓 Pursuing an MBA in Software Architecture and going deeper into AppSec & DevSecOps

🌎 Based in Brazil · **Open to remote (US/CA time zones) & relocation**
