# Olá, eu sou o Lucas Mol 👋

**Senior Software Engineer · Backend & Sistemas Distribuídos**
Java · Spring Boot · Go · Microsserviços · Kafka · AWS

Desenvolvo e modernizo sistemas backend para plataformas críticas e de alto tráfego, com mais de 7 anos de experiência em serviços financeiros, setor público e projetos de pesquisa.

- 🏗️ **Arquitetura de software & sistemas distribuídos:** DDD, design patterns e padrões de resiliência (ex.: deadline propagation) aplicados a microsserviços multi-tenant 24/7 e arquiteturas assíncronas e orientadas a eventos
- ⚡ **Performance:** redução da latência p99 de ~15s para ~3s ao migrar integrações com terceiros para processamento assíncrono; tempo médio de resposta 88,5% menor em uma plataforma legada
- 🔄 **Modernização:** liderei a migração de um monólito Java 8 para microsserviços Spring Boot e schedulers em Go
- 🔐 **Segurança:** single sign-on com OIDC / OAuth 2.0 entre múltiplos serviços; práticas de DevSecOps em todo o ciclo de desenvolvimento
- 🚀 **Entrega & observabilidade:** deploys em Kubernetes com Helm, ArgoCD e canary releases; Datadog, Splunk e Grafana
- 🎓 Cursando MBA em Arquitetura de Software e me aprofundando em AppSec & DevSecOps

🌎 Baseado no Brasil · **Aberto a trabalho remoto (fusos EUA/Canadá) & relocação**
